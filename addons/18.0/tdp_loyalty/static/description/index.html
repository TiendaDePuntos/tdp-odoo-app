Tienda de Puntos

Loyalty points and reward redemption, right from your Point of Sale.

Tienda de Puntos is a customer loyalty platform. This module connects your Odoo Point of Sale to your Tienda de Puntos account so every sale rewards your customers and your cashiers can hand over prizes without leaving the POS.

What it does

  • Points on every sale. When a POS order is validated, the customer's email or ID is sent to Tienda de Puntos and the points are credited. Sending is idempotent, so a retry never doubles the points.
  • Reward redemption at the counter. A "Validar premio TDP" button in the Point of Sale lets the cashier look up a redemption code, see the prize and the customer, and mark it as delivered.
  • Customers stay in sync. Customers created in Tienda de Puntos are pushed into Odoo as contacts.

No server-side code

The module only adds configuration fields to your Point of Sale and a screen to the POS interface. There is no custom Python, no scheduled action and no inbound webhook, so it runs the same on Odoo Online, Odoo.sh, on-premise and Community.

Setup

  1. Install this module. On Odoo Online, enable the developer mode and use Apps > Import Module with the ZIP file for your Odoo version. On Odoo.sh, on-premise or Community, drop the folder in your addons path and install it from Apps.
  2. Get an Odoo API key. Open your user preferences, go to Account Security and create a new API key. Odoo Online requires a plan with external API access.
  3. Connect from Tienda de Puntos. In your Tienda de Puntos back office, open Integrations, choose Odoo and enter your Odoo URL, database and API key.
  4. Check the Point of Sale settings. The Tienda de Puntos block in Point of Sale > Settings will show the gateway, the API key and the branch that were filled in for you.

Requirements

  • An active Tienda de Puntos account with at least one branch.
  • The Point of Sale application installed.
  • External API access enabled on your Odoo plan (needed to create the connection).
